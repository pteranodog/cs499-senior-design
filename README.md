# Pira-See

## Getting Started (In-App)

The app can be accessed currently at https://pirates.drewearly.com/.

To make a new run:

1. Click "Create run"
2. Name the run
3. Set a start time and duration
4. Select a region
5. Adjust particpant rates
6. Click "Select" then "View Run"
7. Click "Start"

To import a run:

1. Click "Import Run"
2. Click "Select"
3. Click "View"

Notes:

1. To compare runs, select two runs for the same region
2. You cannot edit the settings of an imported run

## Development Build

The steps to build and test locally are as follows:

1. Install Docker and Docker-Compose.
2. Run `docker compose up --build` in the project root directory.
3. Navigate to http://localhost:3000/ in your browser.
